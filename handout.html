そもそも何をしているの？

「GASでWebアプリ」と聞くと難しそうですが、やっていることはシンプルです。

セミナーやイベントのあと、Googleフォームでアンケートをとりますよね。その回答データはスプレッドシートに溜まっていきます。でも毎回「関数で集計して…グラフ作って…」と手作業でやるのは大変。
そこで GAS（Google Apps Script） の出番です。GASはGoogleのサービスに最初から組み込まれたプログラミング環境。特別なサーバーやサービスを契約しなくても、スプレッドシートのデータを読み取って、グラフ付きのWebページを自動で表示できます。
つまり今日やっていることを一言でまとめると、「フォームの回答を、URLにアクセスするだけで見られるグラフ付きダッシュボードに変えた」ということです。料金は0円。Googleアカウントだけで動きます。

Part 2

doGet() – GASをWebアプリにする魔法の関数

「スクリプトにURLを与えて、ブラウザから見られるようにする」仕組みです。

普通、Webサイトを作ろうと思ったらサーバーを借りて…ドメインを設定して…と大変ですよね。GASでは doGet() という名前の関数を1つ書くだけで、Googleが自動的にURLを発行してくれます。そのURLにアクセスすると、自分が書いたHTMLページが表示される。これがGAS WebAppの仕組みです。
1

doGet() 関数を書く

「このURLにアクセスされたら、このHTMLファイルを表示してね」という指示書です。たったこれだけ。

function doGet(e) {
  const page = e.parameter.page || 'index';
  return HtmlService
    .createHtmlOutputFromFile(page)
    .setTitle('ダッシュボード');
}

e.parameter.page は URLの末尾に ?page=dashboard のように付けると表示するページを切り替えられます。何も付けなければ index.html を表示します。

2

デプロイ（公開）する

コードを書いたら「公開」ボタンを押すイメージです。URLが発行されて、誰でもアクセスできるようになります。

  1. 1. Apps Script エディタで「デプロイ」→「新しいデプロイ」
  2. 2. 種類を「ウェブアプリ」に
  3. 3. アクセスできるユーザーを「全員」に
  4. 4. 「デプロイ」を押す → URLが出てくる！
Part 3

google.script.run – 画面とデータをつなぐ

Webページ（HTML）からスプレッドシートのデータを取りに行く仕組みです。

ダッシュボードの画面（HTML）は、見た目だけのファイルです。データは持っていません。「スプレッドシートから最新の回答データを取ってきて！」とお願いする仕組みが google.script.run です。

やり取りはこんなイメージ：
HTML画面「データちょうだい！」→ GAS「はい、集計結果です」→ HTML画面「ありがとう、グラフ描くね」
dns

GAS側 – データを準備する係

スプレッドシートのデータを読み取って、「回答数」「満足度の平均」などを計算して返します。

// SurveyAggregate.gs
function getDashboardData() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName('回答');
  const data = sheet.getDataRange().getValues();

  // 1行目はヘッダーなので除外
  const rows = data.slice(1);

  // 集計
  const totalCount = rows.length;
  const avgSatisfaction = rows.reduce(
    (sum, r) => sum + r[5], 0
  ) / totalCount;

  return {
    totalCount: totalCount,
    avgSatisfaction: avgSatisfaction.toFixed(1),
    rows: rows
  };
}
computer

HTML側 – データを受け取って画面に表示する係

「データ取ってきて」→「受け取ったら画面に数字を入れてグラフを描く」という流れです。

// dashboard.html の中
google.script.run
  .withSuccessHandler(function(result) {
    // ↑ データが届いたらここが動く
    document.getElementById('total').textContent
      = result.totalCount;       // → 「21件」
    document.getElementById('avg').textContent
      = result.avgSatisfaction;  // → 「4.5」

    // グラフを描く
    renderCharts(result);
  })
  .withFailureHandler(function(err) {
    console.error('データ取得失敗:', err);
  })
  .getDashboardData();
  // ↑ GAS側の関数名をそのまま書くだけ

lightbulb ここがポイント

普通のWebアプリだと、サーバーへのリクエスト方法（API）を自分で設計する必要がありますが、GASでは関数名をそのまま書くだけ。HTML側から .getDashboardData() と書けば、GAS側の getDashboardData() が自動で呼ばれます。

Part 4

Chart.js – データをグラフにする

無料のグラフ描画ライブラリ。1行読み込むだけで使えます。

Part 3でGASからデータを受け取りました。でも数字の羅列だけでは見にくいですよね。Chart.js は、データを渡すだけで棒グラフや円グラフなどをきれいに描いてくれるツールです。インストール不要、HTMLに1行追加するだけで使えます。
1

HTMLに1行追加するだけ

この1行でChart.jsの全機能が使えるようになります。

<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
2

棒グラフを描く

「どのデータを」「どんなグラフで」表示するかを指定するだけ。回ごとの満足度を棒グラフにする例です。

new Chart(ctx, {
  type: 'bar',              // ← グラフの種類
  data: {
    labels: ['第1回','第2回','第3回'],
    datasets: [{
      label: '満足度（5段階）',
      data: [4.2, 4.5, 4.8], // ← 数値データ
      backgroundColor: '#01A8D3',
      borderRadius: 6
    }]
  },
  options: {
    responsive: true,
    scales: { y: { min: 1, max: 5 } }
  }
});

type を 'line' にすれば折れ線グラフ、'doughnut' にすれば円グラフに。値を変えるだけで切り替えられます。

3

ドーナツチャートを描く

理解度の内訳を円グラフ（ドーナツ型）で表示する例です。

new Chart(ctx, {
  type: 'doughnut',         // ← ドーナツ型
  data: {
    labels: ['よく理解','だいたい','半分','あまり'],
    datasets: [{
      data: [42, 35, 18, 5], // ← 人数や割合
      backgroundColor: [
        '#01A8D3', '#4DC9E6',
        '#EEB730', '#F5DFA0'
      ]
    }]
  },
  options: {
    responsive: true,
    cutout: '60%'            // ← 穴の大きさ
  }
});

lightbulb グラフの種類いろいろ

Chart.js では type の値を変えるだけで、bar（棒）、line（折れ線）、doughnut（ドーナツ）、pie（円）、radar（レーダー）など様々なグラフが描けます。デザインの細かい調整も options で自由自在です。
